# Particle Jester prompts

Copy a prompt into Codex with the skill installed. Add your pack path, Bedrock version and preferred colors where relevant.

## Create effects

- Use $particle-jester to create a purple Nether portal with inward spiraling sparks, a glowing rim and a short opening burst. Make original textures and editable RP files.
- Use $particle-jester to create a lava eruption: warning cracks, rising embers, a central burst and fading smoke. Keep the effect under four seconds.
- Use $particle-jester to build a boss attack with a two-second warning ring, a beam and an impact shockwave. Include a bounded Script API trigger for my project's target version.
- Use $particle-jester to make a healing aura around an entity: green motes, a soft glow and a brief pulse. Explain the attachment and stop conditions.
- Use $particle-jester to create a snowstorm with near and far layers and low, medium and high density settings.

## Improve an existing pack

- Use $particle-jester to inspect this pack and trace the effect from its trigger through animations, particle IDs and texture paths. Report missing or ambiguous links.
- Use $particle-jester to inspect this ZIP containing multiple packs. Expand nested archives explicitly; accept JSONC only when needed and report incomplete coverage.
- Use $particle-jester to fix this invisible particle. Check material, alpha, UV bounds, identifiers and callers before proposing a correction.
- Use $particle-jester to reduce this effect's cost while keeping its silhouette. Compare particle count, lifetime, texture size and overlapping layers.
- Use $particle-jester to make this effect configurable through size, color and intensity inputs. Trace each input to the spawn call and validate its range.

## Preview and deliver

- Use $particle-jester to preview this effect at its beginning, middle, peak and end. Inspect timing, scale and fades, correct visible defects and recapture changed assets.
- Use $particle-jester to package my original effects into editable RP/BP folders and an importable mcaddon. Validate the archives and distinguish static checks, previews and Minecraft runtime tests.
