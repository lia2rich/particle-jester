# Particle Jester: fundamentals

Use for an emitter, motion or timing question that does not require broad orchestration. Separate emitter duration, particle tail and trigger lifetime. Choose one rate, shape and emitter-lifetime alternative; preserve explicit termination.

Determine units before authoring. Billboard size is a half extent; texture margins alter visible scale. Use stable random variables for distributions. Check actor context before entity AABB or local-space attachment claims. Dynamic translation with parametric rotation can differ from competing positional models; inspect the actual components.

Read pinned contracts for exact keys, run validate with the actual texture, and inspect motion/termination in preview. A component catalog establishes names, not visual quality or engine runtime.
