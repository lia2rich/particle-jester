# Particle Jester: animation

Use for a particle attached to a model, animation keyframe, controller state, event chain or unresolved trigger. Trace actual identifier → client alias → animation/controller owner and locator. Include BP trigger evidence when available; preserve missing-owner uncertainty.

Choose bounded keyframes for bursts and state-owned emitters for sustained effects. Repeated keyframes can accumulate loops. Validate locator names, model-to-block units, local space and binding. Named particle event references must resolve; sequence nodes have no implicit time delay.

Run scan and trace, inspect keyframe pre-expressions/conditions and confirm the entire resource stack. Preview attachment through a real Blockbench connection when available; the detached local bridge cannot prove actor-following behavior. Verify state entry/exit and entity lifecycle in Bedrock.
