# Particle Jester: preview

Use for actual visual iteration, screenshot inspection or preview integration. First discover a real Snowstorm particle MCP if available; otherwise evaluate verified Blockbench desktop tools, Snowstorm UI through Playwright, then the supported local bridge. A configuration file is not a connection.

For this repository, `npm run studio` and `tools/preview.mjs` use the inspected Wintersky interface. Set intended camera, distance, scene, seed, parameters and explicit early/middle/peak/end times. Capture each layer and the combined sequence. Inspect shape, color, motion, scale, opacity, density and timing; correct observed defects and repeat.

Capture tools intentionally leave previewVerified false. Approve only after actual image inspection, writing criteria/notes and binding inspection.json to the report and asset hashes. The evidence auditor rejects stale captures. Leave Minecraft runtime verification false unless the exact target client was tested with reviewed evidence.

Read [detailed engineering guidance](../../../../references/preview.md) for the relevant contracts and examples. Common compatibility, tool and verification rules are in [Particle Jester](../../SKILL.md).
