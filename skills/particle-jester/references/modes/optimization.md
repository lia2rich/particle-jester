# Particle Jester: optimization

Use for expensive effects, count/lifetime/collision/overdraw analysis or mobile/console quality tiers. Estimate per-emitter density and overlapping layers/actors; retain unknown dynamic bounds. Count alone does not measure translucent overdraw.

Preserve requested visual scale, principal silhouette layers and stage timing. Scale decorative rates/caps together; avoid truncating a steady effect accidentally. The optimizer writes count/cap candidates and a diff, not a visual-equivalence certificate.

Compare identical camera/time captures, including lowest quality and combined layers. Record target-device graphics mode, repeated cast load, frame/tick behavior and cleanup in actual Bedrock. Do not invent universal safe mobile budgets or claim performance from file size.

Read [detailed engineering guidance](../../../../references/optimization.md) for the relevant contracts and examples. Common compatibility, tool and verification rules are in [Particle Jester](../../SKILL.md).
